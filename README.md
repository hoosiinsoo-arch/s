# کتابخانه زمهریر — نسخه نهایی

این نسخه شامل افزودن تکی کتاب، مدیریت کتاب‌ها، و **افزودن گروهی کتاب‌ها از طریق ZIP + CSV** است.

## افزودن گروهی کتاب‌ها

از مسیر:

`⚙️ مدیریت` → `📚 مدیریت کتاب‌ها` → `📦 افزودن گروهی کتاب‌ها`

یک ZIP بساز که داخل آن `books.csv` و فایل‌های کتاب قرار داشته باشند.

نمونه CSV:

```csv
filename,title,author,category,description,year
001.pdf,نام کتاب,نام نویسنده,📚 ادبیات,توضیحات کتاب,1403
002.pdf,کتاب دوم,نویسنده دوم,📖 رمان و داستان,,1402
```

ستون‌های الزامی: `filename,title,author,category`

ستون‌های اختیاری: `description,year`

نام فایل باید دقیقاً با فایل داخل ZIP مطابقت داشته باشد. دسته‌بندی CSV باید از قبل در ربات وجود داشته باشد.

ربات برای هر فایل، آن را به‌صورت موقت به چت خصوصی مدیر می‌فرستد تا `file_id` تلگرام دریافت شود و سپس پیام فایل را حذف می‌کند. کتاب در دیتابیس ثبت و مستقیماً منتشر می‌شود.

## Render

- ربات یک health endpoint روی `PORT` محیط Render ارائه می‌کند: `/health`
- برای جلوگیری از خواب سرویس Free، باید یک سرویس مانیتور خارجی هر 5 تا 10 دقیقه آدرس `/health` را درخواست کند.
- توکن ربات داخل کد قرار ندارد؛ در Render در Environment Variables مقدار `BOT_TOKEN` را تنظیم کن.
- دیتابیس SQLite روی Render Free ماندگار نیست و برای اطلاعات مهم بهتر است بعداً به PostgreSQL منتقل شود.
